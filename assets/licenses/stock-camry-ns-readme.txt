DESCRIPTION
-----------
A low poly NASCAR-style stock car (Toyota Camry NS) modeled
for game engines and real-time rendering. Built with clean
topology, strategic edge flow, and verified mesh integrity.

WHAT'S INCLUDED
---------------
  stock_camry_ns.glb   — GLTF Binary (recommended, color embedded)
  stock_camry_ns.fbx   — Autodesk FBX
  stock_camry_ns.obj   — Wavefront OBJ + MTL
  preview/             — 5-angle render preview (Hero, Profile,
                         Rear 3/4, Front Face, Clean Tail)
  README.txt           — This file

TECHNICAL SPECS
---------------
  Style         : Low Poly Hard Surface
  Polygon type  : Triangulated, game-ready
  Scale         : Real-world (approx. 1.95 x 4.88 x 1.38 m)
  Pivot point   : Origin to geometry center
  Transform     : All transforms applied (scale, rotation)
  Non-manifold  : 0 edges (QC verified)
  Bad contiguous: 0 edges (QC verified)
  Texture       : Flat color (embedded in GLB/FBX)
  Rigged        : No
  Animated      : No

ENGINE COMPATIBILITY
--------------------
  Godot 4.x     : Recommended — import GLB directly
  Unity         : FBX or GLB
  Unreal Engine : FBX
  Blender       : GLB or FBX

IMPORT TIPS
-----------
  - GLB is self-contained, no external texture files needed
  - FBX and OBJ share the same material color data via MTL
  - Model is centered at world origin, ready to snap/place
  - No hidden geometry, no loose vertices
